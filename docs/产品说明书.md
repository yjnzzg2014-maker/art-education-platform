## 1. 产品概述

### 1.1 这是什么

"创意装饰家"是一套面向小学美术课堂的教学辅助平台，由两个相互配合的子系统组成：

| 子系统 | 名称 | 定位 |
|--------|------|------|
| 创作端 | 课堂实时创作工具 | 学生在平板/电脑上完成装饰创作，教师实时监控全班进度 |
| 分析端 | AI 智能分析平台 | 对学生作品进行四维评分、色彩分析、异常检测，辅助教师教学研究 |

两个系统共享同一个学生与作品数据库。学生在创作端完成的作品会自动进入分析端，供教师进行后续的评估和教研。

### 1.2 适合谁用

- **小学美术教师**：在课堂上组织学生创作、实时监控、课后分析作品
- **教研组长 / 教研员**：查看学校/年级/班级三级数据，跟踪教研闭环
- **学校管理者**：通过数据看板了解全校美术教学整体情况

### 1.3 核心设计理念

> **AI 辅助观察，而非 AI 替代评价。**

平台输出的所有分数和分析结果都是"描述性数据"，不构成对学生的评价性结论。所有教学决策必须经过教师的"释义"环节，由教师做出最终的专业判断。学生本人不会看到任何评分。

## 2. 功能说明 -- 创作端

创作端是一个基于 HTML5 Canvas 的在线绘画工具。学生使用平板或电脑浏览器打开学生页面进行创作，教师同时在教师控制台上监控全班情况。所有操作通过网络实时同步。

### 2.1 学生创作界面

#### 2.1.1 三种创作模式

创作端提供三种模式，由教师在控制台统一切换：

**（1）对称装饰模式（默认）**

[截图：对称装饰模式界面 -- 中央太阳底图周围放置装饰素材]

- 画面中央是一个圆形的"太阳"底图，学生从屏幕左侧的素材面板中选择装饰素材，点击后素材会自动出现在太阳周围
- 素材分为"点"和"线"两个类别，可通过顶部标签切换
- 每个素材放置后会自动"朝向中心"，营造放射对称的装饰效果
- 学生可以用手指拖动素材改变位置，双指捏合可以缩放和旋转素材

**（2）拟人化模式（人脸模式）**

[截图：拟人化模式界面 -- 太阳底图上放置五官零件]

- 太阳变成"脸"，屏幕右侧出现五官面板
- 五官分为四类：眼睛（5 种）、鼻子（3 种）、嘴巴（5 种）、其他（腮红、眉毛、雀斑、眼镜等）
- 学生选择五官零件后，零件会出现在太阳面部的预设位置上
- 同一类别只保留一个（例如选了"大笑嘴"后再选"微笑嘴"，大笑嘴会被替换）
- 每个五官零件也可以拖动位置、缩放和旋转

**（3）自由绘制模式**

- 同时开放装饰素材面板和五官面板，学生可以自由组合装饰和五官
- 适用于开放式创作任务

#### 2.1.2 染色功能

[截图：屏幕右侧的颜色面板 -- 彩虹色系列表]

- 在对称装饰模式下，屏幕右侧会显示颜色面板
- 提供 9 个色系（红、橙、黄、绿、蓝、紫、粉、棕、黑），每个色系有 5 个从浅到深的色阶
- 点击色系名称展开色阶选择器，选中后放置的新素材会自动着色
- 选中已有素材后再点击颜色，可以改变该素材的颜色
- 点击"原"按钮可恢复素材原色（无染色）

#### 2.1.3 太阳皮肤

[截图：屏幕底部的皮肤选择器 -- 6 种太阳底图样式]

- 学生可以选择 6 种不同的太阳底图风格：黏土饼、早安、番茄、紫罗、卡通、简约
- 切换皮肤有 15 秒冷却时间，防止频繁切换

#### 2.1.4 操作工具栏

[截图：屏幕顶部的工具按钮]

| 按钮 | 功能 |
|------|------|
| 撤销 | 撤回上一步操作（最多保留 20 步历史） |
| 清空 | 清除画面上所有素材和五官 |
| 复制 | 复制当前选中的素材 |
| 删除 | 删除当前选中的素材 |
| 上移一层 | 将选中素材移动到上一层（遮挡关系） |
| 下移一层 | 将选中素材移动到下一层 |

#### 2.1.5 其他交互细节

- **素材重叠点选**：当多个素材重叠时，连续点击同一位置可以循环切换选中不同素材，屏幕上会显示"1/3"这样的提示
- **画布外删除**：将素材拖到画布边界以外即自动删除
- **断线重连**：如果网络断开，学生端会显示"正在重新连接..."的遮罩，恢复连接后自动同步所有状态
- **全屏模式**：进入创作后自动进入全屏，右上角有退出按钮
- **水果昵称**：每位学生加入时系统自动分配一个水果名（如"苹果""草莓"），用于在教师端和展示环节保护隐私

### 2.2 教师控制台

教师控制台是教师在课堂上使用的管理界面，可以在电脑或平板浏览器中打开。

#### 2.2.1 实时学生监控

[截图：教师控制台主界面 -- 学生卡片网格]

- 所有已连接的学生以卡片形式排列，每张卡片上实时显示该学生的画布缩略图
- 缩略图每 2 秒自动刷新一次
- 卡片下方显示学生的水果昵称
- 如果学生断线，卡片会变灰并标记为"已断开"
- 点击任意学生卡片可以放大查看该学生的作品详情

顶部显示当前在线学生数量。

#### 2.2.2 模式切换与锁定

[截图：控制台顶部的模式切换按钮和锁定按钮]

| 控制项 | 说明 |
|--------|------|
| 装饰模式 | 切换到对称装饰模式，所有学生同时生效 |
| 人脸模式 | 切换到拟人化模式，所有学生同时生效 |
| 自由模式 | 切换到自由绘制模式 |
| 锁定操作 | 锁定后学生无法进行任何操作，适合教师讲解时使用 |

#### 2.2.3 倒计时功能

[截图：倒计时设置区域]

- 输入时间（单位：秒）后点击"开始"
- 学生端屏幕上方会出现倒计时显示
- 倒计时结束后，系统自动锁定所有学生操作
- 教师可以随时取消倒计时

#### 2.2.4 素材数量限制

| 设置项 | 说明 |
|--------|------|
| 素材上限 | 设置每位学生最多可放置的素材数量（默认 24 个）。输入 0 表示不限制 |
| 频率限制 | 设置在指定时间窗口内最多可放置的素材数（默认 8 秒内最多 3 个），防止学生快速乱放 |

学生端会显示"素材 12/24"这样的计数提示。超出限制时会弹出"素材已满"或"操作太快"的提示。

#### 2.2.5 作品展示

教师控制台提供三种展示模式，用于课堂上展示优秀作品：

**（1）单幅特写（Showcase）**

[截图：选中学生后的展示对话框]

- 在学生卡片上选中某位学生后，点击"展示"按钮
- 可选择"冻结展示"（显示当前状态的快照）或"实时展示"（实时同步该学生的操作）
- 其他学生屏幕上会出现该作品的全屏展示，下方显示作者的水果昵称
- 被展示的学生自己屏幕上会看到"你的作品正在被展示"的提示

**（2）画廊轮播（Gallery）**

[截图：画廊选择模式 -- 多个学生卡片被勾选]

- 点击"画廊选择"按钮进入选择模式
- 在学生卡片上逐个点击勾选要展示的作品
- 点击"开始画廊"后，所有学生屏幕上会出现一个太空主题的画廊动画，被选中的作品在星空背景中缓缓滚动展示
- 每幅作品下方标注作者的水果昵称

**（3）照片画廊（Photo Gallery）**

- 点击"照片画廊"按钮可启动课堂实拍照片的轮播展示
- 照片以卡片翻转的动画效果逐张切换，配有粒子特效和背景音乐

#### 2.2.6 自定义素材管理

[截图：素材管理区域 -- 展开的折叠面板]

教师可以为学生添加自定义的创作素材：

**绘制素材**
- 点击"绘制素材"按钮打开绘制工具
- 提供 10 种颜色、可调粗细的画笔、5 种笔刷样式（实心圆、空心圆、方形、星星、斜线）
- 支持基础图形（圆形、方形、直线、箭头）
- 有橡皮擦和清空功能
- 保存时可命名并选择"点"或"线"的分类

**导入素材图片**
- 点击"导入素材"按钮可上传本地图片作为素材
- 需要输入素材名称并选择分类

**导入五官图片**
- 点击"导入五官"按钮可上传五官零件图片
- 需要输入名称并选择类别（眼睛/鼻子/嘴巴/其他）

**管理已有素材**
- 自定义素材和五官以卡片形式展示
- 支持单个删除
- 素材支持多选和批量删除（勾选 + "全选" + "删除选中"）

所有自定义素材在保存后会立即同步到所有学生端。

#### 2.2.7 清除所有学生

- 点击"清除所有学生"按钮（需二次确认）会清空所有学生连接和画布状态
- 学生端会自动重新加入，获得新的水果昵称和空白画布
- 适用于新一轮课堂开始前的重置

## 3. 功能说明 -- 分析端

分析端是一个网页应用，需要登录后使用。默认提供两个账户：

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | admin123 |
| 教师 | teacher | teacher123 |

登录后进入主界面，左侧是导航栏，分为四个功能组：

| 功能组 | 包含页面 |
|--------|----------|
| 工作台 | 数据看板、工作台 |
| 作业分析 | 批量作业分析、单幅作品诊断 |
| 学生发展 | 素养画像、纵向成长追踪、异常发展预警 |
| 教研协同 | 教研管理、释义记录 |

### 3.1 工作台（Dashboard）

[截图：工作台首页 -- 统计卡片和任务列表]

工作台是登录后的首页，提供全局概览：

**顶部统计卡片（4 个）**
- 进行中任务数
- 本月分析作品数
- 班级平均评级（A/B/C/D）
- 异常作品数

**分析任务列表**
- 显示所有已创建的分析任务
- 支持按状态筛选：全部 / 已完成 / 进行中
- 每个任务显示主题、班级、创建日期和状态
- 点击任务可跳转到批量分析报告页面

**新建分析任务**
- 点击右上角"+ 新建分析任务"按钮
- 在弹窗中选择班级、输入作业主题（如"我眼中的春天"）
- 创建后自动跳转到该任务的分析页面

#### 操作步骤

1. 登录系统后，您会看到工作台首页
2. 如果是第一次使用，点击"+ 新建分析任务"
3. 选择您要分析的班级，输入本次作业的主题
4. 点击"创建"，系统会跳转到分析页面

### 3.2 批量作业分析

[截图：批量分析报告页面 -- 统计图表和作品缩略图]

这是分析端的核心功能，用于对一个班级的整批作品进行AI分析和统计。

**页面顶部**
- 面包屑导航：作业分析 / 班级名 / 主题名
- 操作按钮：导入作品、开始/重新 AI 分析、导出报告 JSON、发起教研讨论

**统计概览（4 个卡片）**
- 已分析作品数及分析耗时
- 班级平均评级和分数
- 主色调倾向及占比
- 异常作品数

**图表区域（3 列）**

| 图表 | 内容 |
|------|------|
| 评级分布 | 柱状图，显示 A/B/C/D 各等级的作品数量和百分比 |
| 四维评分统计 | 色彩运用、构图完整度、主题契合度、造型表现力四个维度的最小值、最大值、均值 |
| 色彩分布 | 11 种颜色（红橙黄绿青蓝紫粉棕灰黑）的使用占比 |
| 构图类型 | 环形图，展示居中式、满幅式、分割式、留白式四种构图类型的占比 |

**AI 教学建议**
- 系统根据四维评分数据和色彩分布自动生成教学建议
- 例如："班级整体在'色彩运用'维度表现最佳（均分 82），在'构图完整度'维度相对薄弱（均分 61）。建议在后续教学中加强'构图完整度'方面的针对性训练。冷色系使用占比偏低（12%），可在下一单元引导学生探索冷暖色对比表现。"

**作品缩略图**
- 显示本任务所有作品的缩略图网格
- 点击任意作品可跳转到单幅诊断页面

#### 操作步骤

1. 在工作台选择或新建一个分析任务
2. 点击"+ 导入作品"将学生作品图片上传到系统
3. 点击"开始 AI 分析"，系统会逐幅进行 AI 评分（页面上会显示进度如 "3/20"）
4. 分析完成后，页面自动刷新，展示完整的统计报告
5. 如需保存报告，点击"导出报告 JSON"下载文件
6. 在缩略图区域点击某幅作品，可进入单幅诊断查看详情

### 3.3 单幅作品诊断

[截图：单幅诊断页面 -- 左侧作品图片，右侧评分详情]

这是对单幅作品进行深度分析的页面，从批量分析页面点击作品缩略图即可进入。

**左侧面板**
- 学生姓名（脱敏显示）、班级、学号
- 作品大图
- 作品元信息：编号、采集时间、构图类型
- 操作按钮："重新 AI 分析"和"教师释义"（仅异常作品显示）
- 如有教师释义记录，显示在下方绿色区块中

**右侧面板**

| 区块 | 内容 |
|------|------|
| 四维分数诊断 | 色彩运用、构图完整度、主题契合度、造型表现力四个维度的得分进度条，标注班级均值参考线，并对每个维度给出评语 |
| 总评与详细评语 | AI 生成的综合评价和分维度评语（连接 AI 服务时可用） |
| 异常判定 | 如果作品被标记为异常，显示具体原因（如"暗色占比 65% 超过阈值"） |
| 作品色彩分布 | 该作品的 11 色占比条形图 |
| 学生历史分数趋势 | 折线图，展示该学生多次作业的分数变化轨迹 |

**底部**
- 同任务作品缩略条：显示当前任务的所有作品，点击可快速切换

**四维评分标准**

每个维度分值范围为 0-100，具体含义：

| 维度 | 满分描述 | 评语示例 |
|------|----------|----------|
| 色彩运用 | 色彩丰富且协调 | 80+: "色彩运用丰富且协调，展现出较强的色彩感知力" |
| 构图完整度 | 画面布局合理有层次 | 60-79: "构图基本完整，可进一步优化画面重心" |
| 主题契合度 | 内容紧扣主题要求 | 60 以下: "主题契合度偏低，需引导学生深入理解主题" |
| 造型表现力 | 线条流畅、表现力强 | 80+: "造型表现力突出，线条流畅自信" |

总分为四个维度的加权平均，对应评级：

| 评级 | 分数范围 |
|------|----------|
| A | 85 分及以上 |
| B | 70 - 84 分 |
| C | 60 - 69 分 |
| D | 60 分以下 |

#### 操作步骤

1. 从批量分析页面点击某幅作品进入
2. 查看右侧四维分数，了解作品在各维度的表现
3. 如果作品被标记为"异常"，点击"教师释义"按钮
4. 在弹出的释义窗口中写下您的专业判断，选择是否覆盖（Override）AI 的异常标记
5. 使用底部的缩略条快速切换到下一幅作品

### 3.4 学生素养画像

[截图：学生列表页面 -- 学生卡片网格]

**列表页面**
- 以卡片形式展示所有学生
- 每张卡片显示：姓名首字、姓名（脱敏）、学号、班级、最新评级、是否有异常标记
- 顶部有班级筛选下拉框和统计卡片（学生总数、班级数量、平均评级）
- 点击学生卡片进入个人画像

**个人画像页面**

[截图：学生画像页面 -- 统计数据和历史作品]

- 顶部 4 个统计卡片：作品总数、平均分、主要评级、历史记录数
- 下方展示该学生所有历史作品的缩略图网格
- 每幅作品显示标题、评分和评级

#### 操作步骤

1. 在左侧导航栏点击"学生发展" > "素养画像"
2. 使用班级筛选下拉框选择目标班级
3. 点击目标学生的卡片

### 3.6 异常发展预警

[截图：异常预警页面 -- 统计卡片和异常作品列表]

**异常检测规则**

- **主题偏离**：主题契合度评分低于 40 分

**页面内容**
- 顶部 3 个统计卡片：异常作品总数、待审核数、已审核数

  - 作品缩略图

  - 评分和评级
  - 状态（待审核 / 已审核）
  - 操作按钮

**重要提示**

> 异常标记是一种数据提示，不是对学生的负面评价。例如，一幅以"夜晚"为主题的作品自然会大面积使用深色，这并不代表学生存在问题。教师需要结合教学情境做出判断。

1. 在左侧导航栏点击"学生发展" > "异常发展预警"

## 4. 使用流程

下面是一个完整的课堂教学流程，从课前准备到课后教研：

### 4.1 课前准备（5 分钟）

```
教师电脑 -> 打开创作端教师控制台
         -> 确认创作模式（装饰/人脸/自由）
         -> 如需自定义素材，提前上传或绘制
         -> 设置素材上限和频率限制（根据教学需要）
```

```
教师电脑 -> 打开分析端
         -> 在工作台新建分析任务（选择班级 + 输入主题）
```

### 4.2 课堂创作（15-25 分钟）

```
学生平板 -> 打开学生创作页面 -> 自动连接到教师控制台

教师操作流程：
  1. 确认所有学生已连接（查看在线人数）
  2. 简要讲解后解锁学生操作
  3. 根据教学设计切换模式（如先装饰后人脸）
  4. 实时监控学生进度，放大查看个别作品
  5. 中途可锁定操作进行集中讲评
  6. 设置倒计时（如"还有 5 分钟"）
  7. 倒计时结束，系统自动锁定
```

### 4.3 课堂展示（5-10 分钟）

```
教师操作：
  1. 选择优秀作品 -> 单幅特写展示 -> 全班欣赏
  2. 选择多幅作品 -> 画廊轮播 -> 太空动画展示
  3. （可选）照片画廊展示课堂实拍
```

### 4.4 作品导入与 AI 分析（课后）

```
教师操作：
  1. 在分析端找到对应任务
  2. 点击"导入作品"上传学生作品图片
  3. 点击"开始 AI 分析"
  4. 等待分析完成（系统显示进度）
  5. 查看班级整体报告
```

### 4.5 作品诊断与释义（课后）

```
教师操作：
  1. 进入"异常发展预警"页面
  2. 逐一查看被标记为异常的作品
  3. 点击"标记已审核"按钮
  4. 写下专业释义（如"该生以'暴风雨'为主题，大面积暗色为有意的艺术表达"）
  5. 如 AI 标记不合理，勾选 Override 覆盖
  6. 在"单幅诊断"页面逐幅查看重点关注的作品
```

### 4.6 教研讨论（教研活动）

```
教研组操作：
  1. 进入"教研管理"页面
  2. 选择需要讨论的任务展开详情
  3. 结合 AI 数据和教师释义进行讨论
  4. 在"教研结论"中记录共识和改进方向
  5. 点击"保存结论"
  6. 检查闭环状态 -> 确认所有异常作品已处理
```

### 4.7 数据回顾（学期中/学期末）

```
教师/管理者操作：
  1. 进入"数据看板"查看全校/年级/班级三级数据
  2. 进入"纵向成长追踪"查看个别学生的进步轨迹
  3. 进入"学生素养画像"查看学生的整体表现
  4. 导出报告用于学期总结或家校沟通
```

## 5. 常见问题 FAQ

### 创作端相关

**Q1：学生打开页面后显示空白 / 无法连接怎么办？**

请检查以下几点：
- 确认教师端的创作服务已启动（端口 2500）
- 确认学生平板和教师电脑在同一个 Wi-Fi 网络下
- 让学生刷新页面重试
- 如果多个学生出现同样问题，可能是网络拥堵，建议减少同时连接的设备数

**Q2：学生中途断线了，之前的作品会丢失吗？**

不会丢失。系统会在服务端保存每位学生的作品状态。学生重新连接后，之前的作品会自动恢复。断线超过 30 分钟未重连的学生数据会被清理。

**Q3：学生端能看到自己的评分吗？**

不能。评分和分析功能仅在分析端提供，而分析端需要教师账号登录。学生端只有创作工具，看不到任何评分信息。

**Q4：如何在新一节课开始前重置？**

在教师控制台点击"清除所有学生"按钮。这会清空所有学生连接和画布，学生刷新页面后会以全新状态重新加入。

**Q5：素材上限设置多少合适？**

建议根据学生年级和课程时间调整：
- 低年级（1-2 年级）：10-15 个，防止堆砌
- 中年级（3-4 年级）：20-25 个
- 高年级（5-6 年级）：30 个或不限制

频率限制建议保持默认（8 秒内最多 3 个），可有效防止学生快速乱点。

**Q6：能同时使用装饰模式和人脸模式吗？**

可以。切换到"自由模式"后，装饰素材面板和五官面板同时显示，学生可以自由组合使用。

**Q7：最多支持多少学生同时创作？**

系统内置了 50 个水果昵称，理论上可支持一个班 50 名学生同时在线。实际使用中建议不超过 45 人，以保证网络同步的流畅性。

### 分析端相关

**Q8：AI 分析需要多长时间？**

根据作品数量不同：
- 10 幅作品：约 2-3 分钟
- 30 幅作品：约 7-8 分钟
- 分析过程中页面会显示进度（如"8/30"），您可以继续使用其他功能

**Q9：没有配置 AI 服务（MiniMax API）也能用吗？**

可以。系统在未连接 AI 服务时会自动使用本地算法进行评分。本地算法基于色彩分布、图像特征等数据计算，功能完整但精度不如 AI 模型。分析结果页面会标注评分来源（"AI 评分"或"本地算法"）。

**Q10："教师释义"是什么意思？为什么要做？**

"教师释义"是本平台的核心环节。AI 检测到的异常可能是误判（如主题为"夜晚"的暗色作品），教师需要根据教学情境做出专业判断。释义过程记录了教师的思考，也是教研讨论的素材来源。

**Q11：Override（覆盖）功能有什么用？**

当 AI 错误地将一幅正常作品标记为异常时，教师可以在释义时勾选"Override"，系统会将该作品从异常队列中移出，恢复为正常状态。

**Q12：如何导出分析报告？**

在批量分析页面点击"导出报告 JSON"按钮，系统会下载一个包含完整分析数据的 JSON 文件。此文件包含所有作品的评分、色彩分布、异常标记等信息，可用于进一步的数据处理或存档。

**Q13：数据看板中"学校 -> 年级 -> 班级"的数据来源是什么？**

数据看板汇总了所有分析任务的结果。只有完成了 AI 分析的任务数据才会被纳入统计。因此，请确保分析任务已完成（状态为"已完成"），相关数据才会出现在看板中。

**Q14：学生姓名为什么显示为脱敏状态？**

为保护学生隐私，分析端的所有页面中学生姓名默认脱敏显示（如"张**"）。这是系统的设计原则之一 -- 分析数据面向教师，用于辅助教学，而非用于公开评价学生。
